# Triển khai

Phúc ghi kết quả khảo sát hosting, cấu hình thử và hướng dẫn vận hành trong thư mục này. Bảng so sánh cần nêu: chi phí sau mức miễn phí, hỗ trợ backend và PostgreSQL, giới hạn ngủ/tài nguyên, domain/HTTPS, vị trí máy chủ, cách đặt biến môi trường, backup và điều kiện dùng cho kinh doanh.

Triển khai trên URL thử trước; giữ nguyên GitHub Pages đang chạy cho đến khi có bản thay thế được kiểm tra. Không commit biến môi trường thật, token hoặc thông tin ngân hàng nhạy cảm.
